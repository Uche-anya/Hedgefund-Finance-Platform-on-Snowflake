# Archived Python lessons

This folder preserves the small, local exercises used to build the first version
of Northbridge. They explain positions, settlement, NAV, reconciliation and
publication one step at a time.

The lessons are useful background, but they are not the current operating path.
The active pipeline uses Snowflake, dbt and the replay controller described in
the repository root README. The Python accounting code remains in
`fund_pipeline` because it also provides an independent control calculation.

The pre-trial checklist records the state of the project before Snowflake was
connected. Its claims are historical and should not be used as current status.

Start with [Part 2: saved inputs](docs/lesson_02_landing.md), then follow the
numbered files through [Part 22: exchange calendars](docs/lesson_22_exchange_calendar.md).
